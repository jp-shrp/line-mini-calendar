## LINEミニアプリとは

LINEミニアプリは、LIFF（LINE Front-end Framework）上で実行されるウェブアプリケーションです。
ユーザーはアプリをインストールすることなく、LINE内でサービスを利用できます。

### 定義

> LINEミニアプリは、LIFF上で実行されるウェブアプリで、ユーザーはアプリをインストールせずにサービスを利用できます

### アクセス方法

ユーザーは以下の方法でLINEミニアプリにアクセスできます：

- LINE外部からのパーマネントリンク
- LINE公式アカウント経由
- LINEの検索機能
- LINEメッセージでのシェア

### 構造

LINEミニアプリは以下の要素で構成されます：

- **ヘッダー**: アプリの基本情報を表示
- **ボディ**: アプリのメインコンテンツ

## 主な特徴

### 開発の特徴

- **HTML5のほとんどの仕様が使用可能**
    - 標準的なWeb技術で開発が可能
- **LINE Developersコンソールで開発・管理**
    - 開発環境の設定や管理が容易
- **どなたでも開発可能**（一部地域は制限あり）
    - オープンな開発プラットフォーム

### ビルトイン機能

LINEミニアプリには以下の標準機能が組み込まれています：

#### 1. ユーザーへのサービスシェア機能

ユーザーが友だちにサービスを共有できる機能

#### 2. アクセス権限付与依頼機能

必要な権限をユーザーに依頼する機能

### カスタム機能

以下のカスタム機能を追加実装できます：

#### 1. サービスメッセージ

- 認証済みミニアプリでのみ利用可能
- サービス通知トークンを使用してユーザーにメッセージ送信
- 事前登録されたメッセージテンプレートが必要

#### 2. 決済システム

アプリ内での決済機能を実装可能

#### 3. カスタムアクションボタン

アプリ固有のアクションボタンを追加可能

## 開発ガイドライン

### 1. プラットフォームへの負荷制限

**MUST**: 以下の方法でLINEプラットフォームへの大量リクエストを避けること

- LIFF URL スキーム経由の大量アクセス
- LIFF API経由の大量アクセス
- Service Message API経由の大量アクセス

> 負荷テストを目的に、LINEミニアプリへ大量のアクセスを行ったりしないでください

### 2. ロギング推奨事項

Service Message API リクエストには以下のロギングを推奨：

**必須ログ項目:**

- リクエストタイムスタンプ
- リクエストメソッド
- APIエンドポイント
- レスポンスステータスコード

**オプションログ項目:**

- リクエストボディ
- 通知トークン
- レスポンスボディの詳細

### 3. ユーザー認証解除プロセス

ユーザーがアプリの連携を解除または退出する場合：

**MUST**: 以下の手順を実行すること

1. ユーザーが付与していた権限を取り消す
2. 連携解除の影響についてユーザーに明確に伝える

> ユーザーがその連動アプリに対して認可していた権限を取り消してください

### 4. ベストプラクティス

- **LIFFアプリケーション開発ガイドラインに従う**
- **LINEプラットフォームの利用規約とポリシーを尊重する**
- **アカウント連携/解除について明確にユーザーに伝える**

### 5. 技術的考慮事項

- **レート制限の処理** (429 Too Many Requests)
- **安全な権限管理の実装**
- **透明性のあるユーザー同意メカニズムの提供**

## APIリファレンス

### 主要機能

#### 1. サービスメッセージ

認証済みミニアプリでのみ利用可能な機能です。

**要件:**

- サービス通知トークン
- 事前登録されたメッセージテンプレート

**制限事項:**

- トークンの有効期間: 1年（31,536,000秒）
- トークンあたり最大5件のメッセージ送信可能
- メッセージ送信後にトークンが更新される

#### 2. Common Profile Quick Fill

認証済みミニアプリで利用可能なプロフィール自動入力機能です。

**主要メソッド:**

```javascript
// ユーザーの共通プロフィールを取得
liff.$commonProfile.get()

// ダミープロフィールデータを取得
liff.$commonProfile.getDummy()

// フォームフィールドを自動入力
liff.$commonProfile.fill()
```

**サポートされるプロフィールスコープ:**

- 姓（Family name）
- 名（Given name）
- 電話番号（Telephone）
- 生年月日（Birthday）
- 性別（Gender）

### 認証とアクセス

#### アクセストークン

**推奨**: ステートレスチャネルアクセストークンの使用

**制限事項:**

- 長期間有効なトークンは非サポート
- 短期間有効またはステートレストークンを推奨

#### ユーザー権限

- 明示的なユーザー許可が必要
- 複数言語をサポート
- エラーハンドリングメカニズムを提供

## 認証ステータス

### 未認証ミニアプリ

**ステータス**: 認証審査前の状態

**制限:**

- 一部機能が制限される
- 認証バッジが表示されない

**利用可能な機能:**

- 基本的なLIFF機能
- ユーザープロフィール取得（基本情報）
- メッセージシェア機能

### 認証済みミニアプリ

**ステータス**: 認証審査通過後の状態

**利点:**

- 追加機能の利用が可能
- 認証バッジが表示される
- サービスメッセージの送信が可能
- Common Profile Quick Fillの利用が可能

**追加機能:**

1. **サービスメッセージ**
    - ユーザーへのプッシュ通知
    - メッセージテンプレートの利用

2. **プロフィール自動入力**
    - ユーザー情報の自動取得
    - フォーム入力の簡略化

3. **高度なユーザー情報アクセス**
    - 詳細なプロフィール情報
    - 複数のスコープへのアクセス

## プロジェクトへの適用

### 実装計画

本プロジェクトでは、以下の段階でLINEミニアプリ化を進めます：

1. **Phase 1: 基本機能実装**
    - LIFF SDK統合
    - ユーザー認証実装
    - 基本的なプロフィール取得

2. **Phase 2: 認証申請準備**
    - アプリの完成度向上
    - ガイドライン準拠の確認
    - 必要なドキュメントの準備

3. **Phase 3: 認証取得**
    - LINE認証審査申請
    - 審査対応
    - 認証取得

4. **Phase 4: 高度な機能実装**
    - サービスメッセージ実装
    - プロフィール自動入力機能
    - カスタム機能の追加

### 技術要件

- **Next.js 15.3.2**: SSR/SSG対応
- **LIFF SDK**: LINEプラットフォームとの連携
- **Supabase**: バックエンド・認証基盤
- **TypeScript**: 型安全な実装

### 注意事項

1. **開発環境**: LINE Developers コンソールでの設定が必要
2. **テスト**: 負荷テストはLINEプラットフォームに影響を与えないよう注意
3. **ユーザー体験**: LINE内でのスムーズな操作を重視
4. **セキュリティ**: ユーザー情報の適切な管理と権限制御
