# EIKO Direct - Gitコミットガイドライン

## コミットメッセージフォーマット

### ブランチ名がfeature/EKD-XXの場合

```
EKD-XX: メッセージ内容
```

例:

```
EKD-11: Edge Functionのレスポンス形式を統一化
EKD-15: 商品検索機能のパフォーマンス改善
EKD-08: ユーザー認証フローの修正
```

### 一般的なコミット

```
種別: 変更内容の簡潔な説明
```

種別例:

- `feat`: 新機能追加
- `fix`: バグ修正
- `refactor`: リファクタリング
- `style`: コードスタイル修正
- `docs`: ドキュメント更新
- `test`: テスト追加・修正

## 重要な注意事項

- **自動生成メッセージは含めない**
    - `🤖 Generated with [Claude Code]...` 等は削除
- **Co-Authored-Byは不要**
- **簡潔で明確なメッセージ**を心がける
- **日本語でのコミットメッセージも可**

## コミット前チェックリスト

1. `yarn lint` でリントエラーなし
2. `yarn type-check` で型エラーなし
3. 不要なファイルがステージングされていないか
4. .envファイルや機密情報が含まれていないか

## ブランチ運用

- **main**: メインブランチ
- **feature/EKD-XX**: 機能開発ブランチ
- **dev/XXX**: 開発用ブランチ
