# EIKO Direct - プロジェクト概要

## プロジェクトの目的

EIKO Directは金庫やセキュリティ製品を扱うECサイトです。ユーザーが製品を検索・閲覧・購入できるWebアプリケーションを提供しています。

## 主な機能

- 製品カタログ・検索機能
- ユーザー認証・会員機能
- マイページ（お気に入り、注文履歴、配送先管理等）
- ニュース・ヘルプ機能
- 商品アイコン説明ページ
- カスタム検索機能

## アーキテクチャ

- フロントエンド: Next.js 15.3.2 (App Router使用)
- バックエンド: コーポレートサイトを利用
- モックサーバー: Express.js (.serverディレクトリ)
- 認証: Google OAuth
- 状態管理: Jotai
- データフェッチ: TanStack React Query
- スタイリング: Tailwind CSS 4

## 環境

- Node.js (バージョン指定: .node-version)
- Docker対応 (Makefileでコンテナ管理)
- 開発ポート: 8081 (デフォルト)
