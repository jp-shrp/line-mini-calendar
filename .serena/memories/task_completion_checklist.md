# EIKO Direct - タスク完了時のチェックリスト

## コード品質チェック

1. **リント実行**: `yarn lint`
    - ESLintエラーがないことを確認
    - unused-importsエラーの修正

2. **型チェック**: `yarn type-check`
    - TypeScriptコンパイルエラーがないことを確認
    - strict modeに準拠していることを確認

3. **フォーマット**: `yarn format`
    - Prettierでコードフォーマットを統一

## ビルドテスト

```bash
# プロダクションビルドテスト
yarn build
```

## 機能テスト

- ブラウザでの動作確認
- 関連する画面・機能の動作確認
- レスポンシブデザインの確認

## コードレビューポイント

- 単一責任原則に従っているか
- 共通化できる処理をutil/component/hookに切り出したか
- エラーハンドリングが適切か
- アクセシビリティに配慮しているか

## ドキュメント更新

- README.mdの更新（必要に応じて）
