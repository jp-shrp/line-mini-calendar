# タスク完了時のチェックリスト

## 必須実行項目（MUST）

タスク完了後、**必ず**以下のコマンドを順番に実行すること:

### 1. フォーマット
```bash
yarn format
```
- Prettierでコード整形
- すべてのファイル（.ts, .tsx, .js, .jsx, .json, .md）を対象

### 2. 型チェック
```bash
yarn type-check
```
- TypeScriptの型エラーがないことを確認
- エラーがある場合は修正必須

### 3. リンティング
```bash
yarn lint
```
- ESLintでコード品質チェック
- 未使用インポートの削除
- コーディング規約違反の検出

### 4. テスト実行
```bash
yarn test
```
- すべてのテストが通過することを確認
- 新規機能には対応するテストを追加

## チェック項目

### コード品質
- [ ] TailwindCSSのみ使用（インラインstyleなし）
- [ ] 三項演算子なし（Early return使用）
- [ ] console.logなどのデバッグコード削除
- [ ] 絶対パスインポート（相対パス禁止）
- [ ] any型を使用していない
- [ ] 未使用のインポート削除

### アーキテクチャ
- [ ] Hook+View分離パターン適用（Client Component）
- [ ] SSR/CSR適切に使い分け
- [ ] ビジネスロジックはServiceレイヤーに分離
- [ ] エラーハンドリングが適切

### ドキュメント
- [ ] `.docs/guideline.md`の内容に完全準拠
- [ ] 新規追加した機能のドキュメント更新（必要に応じて）

### Git
- [ ] コミットメッセージがルール準拠（`{タスクID}: メッセージ`）
- [ ] 自動生成メッセージなし

## Stepごとの実行

タスクファイルに「**Stepごとに`yarn format`,`yarn type-check`, `yarn lint`, `yarn test`を実行する事**」と記載がある場合、各Step完了後に上記4コマンドを実行すること。
